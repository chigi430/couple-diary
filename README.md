# 오늘의 우리 (커플 다이어리)

커플이 함께 쓰는 캘린더 + 그날의 사진·기록 앱.
로그인 / 커플 연결 / 실제 저장 / 사진 업로드 / 실시간 공유가 Supabase로 붙어 있습니다.

## 사전 준비 (한 번만)

1. Supabase 프로젝트에서 `supabase-setup.sql` 을 이미 실행했어야 합니다. (SQL Editor → 붙여넣기 → Run)
2. Supabase 대시보드 → **Authentication → Sign In / Providers → Email** 에서
   **"Confirm email"(이메일 확인)을 꺼두세요.** 둘이서만 쓸 거라, 꺼두면 가입 즉시 로그인됩니다.
   (켜두면 가입 후 메일의 링크를 눌러야 로그인돼요.)

## 로컬에서 실행

```bash
npm install
npm run dev
```

터미널에 뜨는 주소(보통 http://localhost:5173)를 브라우저에서 엽니다.

> `.env` 파일에 Supabase 주소/키가 이미 들어 있습니다.
> 값이 비어 화면이 안 뜨면 `.env` 를 확인하세요.

## 처음 사용 흐름

1. 한 사람이 가입 → "우리 공간 만들기" → **초대코드**가 나옵니다.
2. 그 코드를 상대에게 전달.
3. 상대가 가입 → "초대코드로 참여" → 같은 공간에 묶입니다.
4. 이제 둘 중 누가 기록해도 서로에게 실시간으로 보입니다.

## 배포 (나중에)

GitHub 에 올린 뒤 Vercel 에 연결합니다. Vercel 프로젝트 설정의
Environment Variables 에 아래 두 개를 넣어야 합니다.

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_KEY`

## 메모

- 사진은 업로드 전에 클라이언트에서 리사이즈·압축됩니다(무료 저장공간 절약).
- 사진 버킷은 비공개이며, 표시할 때 임시 서명 URL을 발급받아 보여줍니다.
- 공휴일(`src/constants.js`)은 2026년 예시입니다. 실제 서비스에선
  공공데이터포털 특일정보 API로 연도별 자동 처리하는 것을 권장합니다.
- 무료 Supabase 프로젝트는 7일간 요청이 없으면 일시정지됩니다(대시보드에서 재개).
